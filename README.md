DrinkedIn 🍸

DrinkedIn is a social media platform for drink enthusiasts where users can share their favorite drinks, upload photos, interact with posts, follow other users, and explore trending pours.

Built using:

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB Atlas
Image Hosting: Cloudinary
Deployment: Vercel + Render


Features ✨
🔐 JWT Authentication
👤 User Profiles
📸 Image Uploads with Cloudinary
🍸 Create / Edit / Delete Posts
💬 Comments System
🥂 Like (Cheers) System
👥 Follow / Unfollow Users
🌙 Dark / Light Theme
📱 Responsive UI
🔥 Trending Feed
🖼️ Post Image Preview
🏷️ Tags Support
